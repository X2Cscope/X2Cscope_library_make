X2Cscope Library Binary Support Matrix
=======================================

Summary
-------
Use libx2cscope-generic-32dsp-dspic33a-elf.a or
libx2cscope-generic-32dsp-dspic33a-mlarge-elf.a for dsPIC33AK devices.
The combined libx2cscope2-generic-pic24-dspic33-elf.a archive is intended
for the non-MLarge 16-bit XC-DSC families; it is not a validated
multi-architecture library for dsPIC33AK.

The processor options below are taken from the corresponding *.mk build
files. XC-DSC targets use -mcpu=; XC32 targets use -mprocessor=.

Notes
-----
1. Generic binaries target an architecture/family, not necessarily every
   device revision. The application must use a compatible compiler, linker
   configuration, device headers, and memory model.
2. The -mlarge binaries are not interchangeable with the normal variants.
3. The combine step also collects normal dsPIC33AK objects because that
   target uses the shared XC-DSC object directory. However, this produces a
   mixed-architecture archive and should not be considered a validated
   dsPIC33AK library. Use the dedicated dsPIC33AK archive instead.
4. The Cortex makefiles use ARM processor selections, but currently define
   __GENERIC_MICROCHIP_PIC32__ for X2Cscope device-info reporting. Therefore,
   the Cortex binaries are ARM-compatible, while their reported device-info
   family may identify as PIC32.
