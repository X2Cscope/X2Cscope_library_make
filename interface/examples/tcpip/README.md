# X2Cscope — TCP/IP Communication Example (10BASE-T1S / lwIP)

This example implements the X2Cscope communication layer over TCP/IP using the
lwIP stack and a 10BASE-T1S (single-pair Ethernet) physical interface driven by
the LAN8651 / ADIN1110 MAC-PHY (TC6 driver). The reference hardware is the
**dsPIC33AK512MC510** with an XPRO 10BASE-T1S click board.

The same approach applies to any lwIP-enabled target — replace the T1S HAL
with your Ethernet or Wi-Fi interface and the rest of the example is identical.

## Files

### X2Cscope layer (copy into your project's `X2Cscope/` folder)

| File | Purpose |
|---|---|
| `X2CscopeComm.h` | Comm layer header |
| `X2CscopeComm.c` | Comm layer implementation — TX/RX over TCP |
| `../X2Cscope.h` | Public X2Cscope API (copy from `interface/`) |
| `../X2Cscope.c` | Scope buffer + `X2Cscope_Init()` (copy from `interface/`) |

### TCP server driver — `lwip/` (copy into your project's `lwip/` folder)

| File | Purpose |
|---|---|
| `lwip/tcp_server.h` | Lightweight lwIP TCP server — type definitions and API |
| `lwip/tcp_server.c` | TCP server implementation (accept, receive callback, send, stop) |

### DMA-SPI HAL — `hal/` (copy into your project's `hal/T1S/` folder)

| File | Purpose |
|---|---|
| `hal/dmaspi.h` | DMA-assisted SPI HAL interface |
| `hal/dmaspi.c` | DMA channels 0/1 + SPI1 driver for TC6 MAC-PHY communication |

> `hal/dmaspi.c` depends on MCC-generated drivers: `dma/dma.h`, `spi_host/spi1.h`,
> and `system/system.h`. These are generated by MCC Melody and are not included here.

### Additional T1S files (obtain from the reference project or generate via MCC)

| File | Purpose |
|---|---|
| `t1s_lwip_hal.h/.c` | GPIO/I2C/SPI macro abstraction for TC6-lwIP driver |
| `t1s_lwip.h/.c` | TC6-lwIP init, PLCA management, service loop |
| `tc6-lwip.h/.c` | TC6 lwIP integration layer |
| `tc6-stub.h/.c` | TC6 SPI transaction stub |

> The TC6 driver (`tc6-lwip`, `tc6-stub`) and the full lwIP source tree are not
> included here. Obtain them from the
> [Microchip TC6 lwIP driver repository](https://github.com/MicrochipTech/oa-tc6-lib)
> and the [lwIP repository](https://savannah.nongnu.org/projects/lwip/).

## Protocol Overview

X2Cscope uses a byte-stream protocol (LNet). TCP carries it natively — no
additional framing is needed.

- **TX:** `sendSerial()` accumulates bytes into a 516-byte buffer. `flushSerial()`
  sends the buffer as a single TCP segment at the end of each LNet frame,
  minimising TCP overhead and preventing Nagle-algorithm delays.
- **RX:** The TCP server receive callback (`receiveTcpData`) pushes incoming
  bytes into a 256-byte circular buffer. `receiveSerial()` pops one byte at a
  time when the library is ready to process it.

## Hardware Requirements

- **MCU:** dsPIC33AK512MC510 (or any dsPIC33A with DMA + SPI)
- **T1S click board:** XPRO 10BASE-T1S (LAN8651 or ADIN1110 MAC-PHY)
- **Connection:** SPI1 (DMA-assisted) + one GPIO for CS, one for RST, one for INT
- **Network:** 10BASE-T1S bus with at least one other node (e.g. a PC with a
  USB 10BASE-T1S adapter) or a direct point-to-point cable

## MCC Configuration

### SPI1 — host mode, used by the DMA-SPI HAL

1. Add **SPI1** in MCC Melody, host mode.
2. Configure for **8-bit**, **MODE 0,0**, **MSB first**.
3. Clock speed: ≤ 15 MHz (LAN8651 limit).
4. Disable hardware SS — CS is driven manually via GPIO in `dmaspi.c`.
5. Disable SPI RX/TX interrupts — DMA handles transfers.

### DMA — channels 0 and 1 for SPI TX and RX

1. Add **DMA** in MCC Melody.
2. Configure **DMA0** for SPI1 TX (memory → peripheral, source increment).
3. Configure **DMA1** for SPI1 RX (peripheral → memory, destination increment).
4. Enable DMA0 and DMA1 done interrupts.
5. The `dmaspi.c` file registers `DMA0_Callback` / `DMA1_Callback` via
   `DMA_ChannelCallbackRegister()`.

### GPIO pins

| Signal | Direction | Connected to |
|---|---|---|
| `XPRO1_CS` | Output | T1S click CS |
| `XPRO1_RST` | Output | T1S click RST |
| `XPRO1_INT` | Input + interrupt | T1S click INT |

Configure the INT pin as a **change notification interrupt** input. Register
the TC6 interrupt handler via `T1S_EIC_CB_Register()` (called by the TC6-lwIP
driver automatically during `TC6LwIP_Init()`).

### Timer — for `SysTick`

Add a free-running timer (e.g. TMR1 or SCCP1) and configure its period
callback to call `SysTick_Handler()` to maintain the millisecond tick used by
the T1S driver.

## Network Configuration

The IP address, PLCA node ID, and PLCA timing are set at the top of `t1s_lwip.c`:

```c
#define T1S_BOARD_INSTANCE      0               /* node 0 = IP 192.168.0.100 */
#define T1S_PLCA_ENABLE         (true)
#define T1S_PLCA_NODE_ID        (T1S_BOARD_INSTANCE + 1)
#define T1S_PLCA_NODE_COUNT     (8)
#define T1S_PLCA_BURST_COUNT    (0)
#define T1S_PLCA_BURST_TIMER    (0x80)

static const uint8_t m_ip[] = {192, 168, 0, (100 + T1S_BOARD_INSTANCE)};
```

Change `T1S_BOARD_INSTANCE` for each node on the bus (0, 1, 2, …).  
The X2Cscope TCP server listens on port **12666** (set by `X2CSCOPE_TCP_PORT`
in `X2CscopeComm.c`).

## Adapting `X2CscopeComm.c`

Update the TCP server include path and port to match where you placed `tcp_server.h`:

```c
#include "lwip/tcp_server.h"        /* adjust path to your TCP server driver */
#define X2CSCOPE_TCP_PORT  (12666U) /* adjust port if needed                 */
```

## Application Integration

### 1. Copy files

```
Project/
├── X2Cscope/
│   ├── X2Cscope.h              (from interface/)
│   ├── X2Cscope.c              (from interface/)
│   ├── X2CscopeComm.h          (from examples/tcpip/)
│   └── X2CscopeComm.c          (from examples/tcpip/)
├── lwip/
│   ├── tcp_server.h            (from examples/tcpip/lwip/)
│   └── tcp_server.c            (from examples/tcpip/lwip/)
├── T1S/
│   ├── t1s_lwip.h
│   ├── t1s_lwip.c
│   ├── tc6-lwip.h / tc6-lwip.c (TC6 driver — obtain from MicrochipTech/oa-tc6-lib)
│   └── tc6-stub.h / tc6-stub.c (TC6 SPI stub — obtain from MicrochipTech/oa-tc6-lib)
└── hal/T1S/
    ├── dmaspi.h                (from examples/tcpip/hal/)
    ├── dmaspi.c                (from examples/tcpip/hal/)
    ├── t1s_lwip_hal.h
    └── t1s_lwip_hal.c
```

### 2. Add to build system

Add all `.c` files above to your MPLAB X project or CMakeLists.txt.
Add include paths: `X2Cscope/`, `T1S/`, `T1S/inc/`, `hal/`, `hal/T1S/`.
Link `libx2cscope-<target>.a`, `liblwip.a`, and `libtc6.a`.

### 3. Initialise

The T1S network stack must be initialised **before** X2Cscope, because
`X2CscopeComm_PostInit()` calls `tcp_server_start()` which requires lwIP to
be running:

```c
#include "X2Cscope/X2Cscope.h"
#include "T1S/t1s_lwip.h"

int main(void) {
    HAL_Init();             /* system + peripheral init    */
    SysTick_Initialize();   /* millisecond tick            */

    T1S_init();             /* init TC6-lwIP + PLCA        */
    X2Cscope_Init();        /* hooks TCP callbacks, starts server on port 12666 */

    while (1) {
        X2Cscope_Communicate();   /* process X2Cscope protocol */
        T1S_execute();            /* service TC6 + lwIP        */
    }
}
```

### 4. Fixed-rate task — update scope

```c
/* Timer ISR or SCCP callback — called at fixed rate (e.g. 100 µs) */
void SCCP1_TimeoutCallback(void) {
    X2Cscope_Update();
}
```

## Connecting with pyX2Cscope

[pyX2Cscope](https://github.com/X2Cscope/pyx2cscope) v0.6.0 and later supports
TCP/IP (Ethernet). Install it with pip (Python 3.10–3.14):

```
pip install pyx2cscope
```

### Qt GUI

```
pyx2cscope
```

1. Confirm the device is on the network — check UART debug output for
   `"PLCA Mode active"` and note the IP address (e.g. `192.168.0.100`).
2. Select **TCP/IP** (or **Ethernet**) as the interface.
3. Enter the device IP address and port **12666**.
4. Browse to your firmware `.elf` file.
5. Click **Connect**.

### Web GUI (browser-based)

```
pyx2cscope -w
```

Then open the displayed URL in a browser and follow the same steps as above.

### Scripting / automation

```python
from pyx2cscope.x2cscope import X2CScope
from pyx2cscope.interface import InterfaceType

x2c = X2CScope(
    elf_file="path/to/firmware.elf",
    interface=InterfaceType.TCPIP,
    host="192.168.0.100",
    port=12666,
)
my_var = x2c.get_variable("my_variable_name")
print(my_var.get_value())
my_var.set_value(42)
```

For the latest release and standalone binaries visit:
